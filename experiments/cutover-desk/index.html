WHAT THIS IS—AND ISN’T

Built to make responsibilities clear.

Does anything connect to my Microsoft tenant?

No. The workbench reads the CSV in your browser. It never asks for Microsoft credentials, invokes Microsoft APIs, uploads your CSV, or changes permissions. Use client aliases and remove personal data before import.

Is this an automated migration tool?

No. It prepares the readiness evidence and communication workflow. Your authorized technicians and the application vendor own migration decisions, code changes, tenant configuration, permissions, testing and rollback.

Is October 1 a universal outage deadline?

No. Microsoft describes phased, administrator-controllable disablement starting October 1, 2026 and permanent shutdown April 1, 2027. Current tenant settings and application allow-list state must be verified. Check the primary sources below.

Does a report certify that a client is safe?

No. The source report can lag by up to 10 days. Missing activity does not prove no dependency exists. Cutover Desk preserves unknowns and asks for explicit owner and test evidence. Its priority rules are its own—not Microsoft's ratings.

What is actually automated?

CSV validation, grouping, deterministic triage, report generation, document packaging and local batch processing. The current public release does not run autonomous selling agents, send email, take payments, or rewrite your code.

Is this affiliated with Microsoft?

No. Cutover Desk is an independent software product. Microsoft names are used only to identify compatible source reports and official technical guidance. No certifications or endorsements are claimed.
